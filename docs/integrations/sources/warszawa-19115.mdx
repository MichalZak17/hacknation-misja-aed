This is the cleanest source: every field is filled on every record, apart from `access_desc` (612 of 708).

## Mapping to reference fields

| Reference field | From |
|---|---|
| `building_name` | `object_name` |
| `address` | `street` + `building_no` |
| `postal_code`, `city` | `postcode`, `city` |
| `location_detail` | `location_desc` + `device_loc` |
| `indoor` | `device_loc` starts with "Wewnątrz" → true, "Na zewnątrz" → false |
| `access` | `public_access`: Publiczny → public, Prywatny → private |
| `opening_hours_raw` | `access_desc` (free text, not OSM syntax) |
| `manufacturer` | `manufacturer` (free text, often brand and model together) |
| *(not stored)* | `availability`, `specification` |

## Quirks

- **`availability`** (Nie 511, Tak 100, Ograniczona 95) is dropped. It probably means "available around the clock".
  If so, many devices marked `public_access: Publiczny` (608) are only reachable during office hours.
- **`specification`** (Tak 400, Nie 179, Brak informacji 129) is dropped. The feed doesn't document what it means.
- **`manufacturer`** is free text: "Philips", "PHILIPS", "Philips HS1" and "Philips Heartstart HS1" are all the same
  brand. Model is mixed in, e.g. "CU Medical Systems iPAD CU-SP1".
- **`access_desc`** is Polish free text, e.g. "Poniedziałek: godz. 8:00-18:00; …", not OSM `opening_hours`.
