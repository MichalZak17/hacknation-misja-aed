## Mapping to reference fields

| Reference field | From |
|---|---|
| `building_name` | `name` (the whole string, including "Defibrylator (AED 9579) w …") |
| `address` | `street` + `home_number` |
| `postal_code`, `city` | `postcode`, `city` |
| `photo_url` | `gallery[0].url` |
| `teryt` | constant from config |

## Quirks

- This is a **website's points-of-interest export**, not an AED register. It has no access, opening hours or device
  fields.
- **`description`** is generic text about what an AED is: only 3 different versions across 21 records, with no
  device-specific content.
- **The device number is only inside the name** ("AED 9579", sometimes "AED7639"). It isn't extracted to
  `inventory_number` yet. AED 7639 appears twice, written both ways, so it may be a duplicate.
- **Every record has a photo.**
